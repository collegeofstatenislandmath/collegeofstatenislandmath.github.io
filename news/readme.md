# News Stories

* Images can't be pdf here
* using this template is useful or copy an existing news item

```yaml
---
title: TITLE
date: DATE
image: IMAGE
image-alt: DESCRIBE THE IMAGE
Note: (e.g. room number/time)
about:
  template: solana
  image-width: 35%
---

MORE DESCRIPTION
```

Update `/index.qmd` in the root directory to set the number of most recent news
items to display on the main page. In `/news.qmd` you can comment or uncomment
the lines to display a poster image on the main page.
